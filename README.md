# Algorithms — Lab

Part of the **Software-Engineering-Labs** repository. This branch is scoped to a single subject — it contains only the `Algorithms/` lab and this README; the `main` branch holds all subjects.

## What's here

Classic sorting (bubble, insertion, merge, quicksort) and searching (linear, binary) algorithms, plus recursion examples (factorial, memoized Fibonacci, and an N-Queens backtracking solver). Pure Python 3 standard library, with unit tests and a Big-O complexity reference.

```
Algorithms/
├── source/
│   ├── sorting_algorithms.py
│   ├── searching_algorithms.py
│   └── recursion_examples.py
├── tests/
│   └── test_algorithms.py
└── documentation/
    └── README.md
```

# Operating Systems Lab

Part of the **Software-Engineering-Labs** repository. This branch is scoped to a single subject — it contains only the `Operating-Systems/` lab and this README; the `main` branch holds all subjects.

## What's here

A CPU scheduling simulator (FCFS, SJF, Round Robin) comparing waiting/turnaround times, a producer-consumer synchronization demo using locks and semaphores, and a deadlock detector based on a resource-allocation graph.

```
Operating-Systems/
├── source/
│   ├── cpu_scheduling.py
│   ├── producer_consumer.py
│   └── deadlock_detection.py
└── documentation/
    └── README.md
```

# Data Structures — Lab

Part of the **Software-Engineering-Labs** repository. This branch is scoped to a single subject — it contains only the `Data-Structures/` lab and this README; the `main` branch holds all subjects.

## What's here

From-scratch implementations of a singly linked list, a stack and a queue, a binary search tree, a graph (with BFS and DFS traversal), and a hash table using separate chaining for collision resolution. Pure Python 3 standard library, with unit tests and a time-complexity summary.

```
Data-Structures/
├── source/
│   ├── linked_list.py
│   ├── stack_queue.py
│   ├── binary_search_tree.py
│   ├── graph.py
│   └── hash_table.py
├── tests/
│   └── test_data_structures.py
└── documentation/
    └── README.md
```

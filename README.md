# Software Construction Lab

Part of the **Software-Engineering-Labs** repository. This branch is scoped to a single subject — it contains only the `Software-Construction/` lab and this README; the `main` branch holds all subjects.

## What's here

OOP fundamentals applied to a small library-lending domain model, three classic design patterns (Singleton, Factory Method, Observer), and a clean-code before/after refactor. Pure Python 3 standard library, with unit tests.

```
Software-Construction/
├── source/
│   ├── oop_library_system.py
│   ├── design_patterns.py
│   └── clean_code_refactor.py
├── tests/
│   ├── test_oop_library_system.py
│   └── test_design_patterns.py
└── documentation/
    └── README.md
```

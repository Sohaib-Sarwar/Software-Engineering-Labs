# Artificial Intelligence Lab — Classical Machine Learning from Scratch

Part of the **Software-Engineering-Labs** repository. This branch is scoped to a single subject — it contains only the `Artificial-Intelligence/` lab and this README; the `main` branch holds all subjects.

## What's here

Pure-Python (no external ML libraries) implementations of data preprocessing (min-max normalization, z-score standardization, missing-value imputation), a K-Nearest-Neighbors classifier, and a K-Means clustering algorithm, each demoed on a small synthetic dataset defined right in the file.

```
Artificial-Intelligence/
├── source/
│   ├── data_preprocessing.py
│   ├── knn_classifier.py
│   └── kmeans_clustering.py
└── documentation/
    └── README.md
```

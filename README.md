# Web Engineering Lab: Notes App (Client-Server Demo)

Part of the **Software-Engineering-Labs** repository. This branch is scoped to a single subject — it contains only the `Web-Engineering/` lab and this README; the `main` branch holds all subjects.

## What's here

A small full-stack Notes application: a Flask REST API (CRUD endpoints plus a simple token-based auth demo) and a static HTML/CSS/JS frontend that talks to it via `fetch()`.

```
Web-Engineering/
├── backend/
│   └── app.py
├── frontend/
│   ├── index.html
│   ├── style.css
│   └── app.js
└── documentation/
    └── README.md
```

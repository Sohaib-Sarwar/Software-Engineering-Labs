# Computer Networks — Lab

Part of the **Software-Engineering-Labs** repository. This branch is scoped to a single subject — it contains only the `Computer-Networks/` lab and this README; the `main` branch holds all subjects.

## What's here

Socket-programming demos — a TCP echo server/client pair and a single-file UDP demo — alongside a worked subnetting worksheet and notes on the OSI model, TCP/IP model, TCP vs. UDP, DNS, and DHCP.

```
Computer-Networks/
├── simulations/
│   ├── tcp_echo_server.py
│   ├── tcp_echo_client.py
│   └── udp_ping_demo.py
├── configurations/
│   └── subnetting_worksheet.md
└── documentation/
    └── README.md
```
